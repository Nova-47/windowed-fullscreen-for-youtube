# Privacy Policy: Windowed Fullscreen for YouTube

Last updated: 2026-10-13

**This extension does not collect, transmit, sell, or share any personal or usage data.**

- It makes no network requests of its own.
- It stores a single value, whether windowed fullscreen is turned on, using `chrome.storage.local`. This value stays on your device and is removed when you uninstall the extension.
- It runs only on `https://www.youtube.com/*` pages, where it changes the page layout locally to enlarge the video player.
- It requests one permission, `storage`, used solely for the value above.

Questions: open an issue at https://github.com/Nova-47/windowed-fullscreen-for-youtube/issues
